# Tessera — Portfolio

An English-language Go backend portfolio. Static HTML, CSS and JavaScript, with no build step or external runtime dependencies.

## Content

- Commercial warehouse automation case study, with employer and product anonymized.
- Flagr, search-top and Observability Intelligence Agent.
- Technical skills, email and Telegram contacts.
- Responsive layout, keyboard-accessible dialogs and reduced-motion support.

## Files

- `index.html`: page content and metadata.
- `styles.css`: layout and animations.
- `app.js`: navigation and project case studies.

Published with GitHub Pages from the main branch. Preview locally with `python -m http.server 4173`.

Visual composition inspired by Perry Wang’s 2023 portfolio. Text, diagrams and implementation are original. Project visuals are illustrations, not live dashboards.
